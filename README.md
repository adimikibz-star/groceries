# Grocery Shop List

A simple and efficient application to manage your grocery shopping list.

## Features

- Add items to your grocery list
- Remove items from your list
- Mark items as purchased
- Organize items by category
- Track spending and budget

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/adimikibz-star/groceries.git
cd groceries
npm install
```

### Usage

```bash
npm start
```
